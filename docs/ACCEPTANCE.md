## 真人验收表（尚未执行）

执行前记录真实摄像头型号、浏览器版本、模型哈希、光照、距离和配置 JSON。使用均匀室内光照、单人、正面及约 ±30°。至少三位自愿测试者，以匿名编号记录；不上传原始视频。

动作计数方法：每次给出动作提示，在 2 秒窗口内，对应可用目标超过 0.6 且持续至少两个渲染帧算一次响应；恢复到低于0.2后再开始下一次。同时由观察者确认可见动作正确、方向与目标一致；错误侧动作不算成功。上述阈值在正式采集前固定，不事后择优更改。模型缺通道记“不适用”。

每人每项目标≥18/20；60秒中性明显误闭眼/张嘴/微笑≤2次（自然眨眼排除）。规范完整样例基础配置目标≤3分钟。边界场景眼镜/逆光/大侧脸另记，不混入支持范围。

剩余性能/稳定性试验：

1. 720p 摄像头输入、640宽推理、预热后连续采样：稳定渲染≥30FPS（目标60），推理吞吐≥20FPS；处理到渲染提交P95≤100ms。
2. 固定真人静止参数回放对比关闭平滑与自适应，抖动RMS降幅≥30%，另报短眨眼漏检与动作响应延迟。
3. 遮挡2秒恢复，目标1秒内稳定驱动；记录姿态跳变和异常。
4. 连续30分钟，切换模型和摄像头各10次；留浏览器性能轨迹、对象/Worker/轨道数量和内存趋势。
5. 真实设备关闭后摄像头指示灯灭，网络审查无图像上传；清除后刷新、重新导入不恢复旧配置。

这些空项保留为真实验收待办，当前未满足项目计划第11节的最终完成定义。后续开发不应据工程预览状态宣称全设备性能或三人实验已通过。
