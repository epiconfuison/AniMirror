# 阶段 02：本地面部追踪与摄像头控制

日期：2026-09-30。功能实现及模拟设备浏览器验证完成；真实摄像头动作质量待验收。对应 V1-04、V1-05。

## 完成

- 具名 MediaPipe 系数、有效关键点/矩阵检查和 YXZ 头部姿态；数据左右不受视频镜像影响。
- 固定 tasks-vision 0.10.32，下载模型版本 float16/1，SHA-256 校验；运行期全部资源同源。
- Classic Worker 中动态加载 ESM 入口，兼容 WASM 的 importScripts；明确使用 CPU。
- 设备枚举/切换、主动请求权限、暂停/继续、彻底关闭；拒绝/占用/拔出/启动超时提示。
- 720p 摄像头请求、640 宽缩图，最多一帧在途（包含异步 bitmap），过忙帧丢弃。
- 关闭时终止 Worker、全部轨道和 RAF；权限弹窗晚返回也立即停止已过期的流。

## 验证

- `tests/unit/tracking.test.ts` 4/4：具名左右及组合旋转、完整有效检测、丢帧门控、设备错误与异步启动取消。
- `tests/e2e/camera.spec.ts` 2/2：Edge 实际本地 WASM/Worker 初始化与模拟视频推理；暂停轨道仍 live，关闭后全部 ended；拒绝权限可重试；期间外部 HTTP 请求为零。
- 以上模拟视频没有真实人脸，不能据此声明真人追踪成功率或吞吐达标。
